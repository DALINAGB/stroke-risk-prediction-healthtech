## 🩺 El Problema Clínico
El infarto cerebral es una de las principales causas de discapacidad a nivel mundial. Como médico, mi objetivo con este análisis es transformar datos crudos en una herramienta de **estratificación de riesgo** que permita intervenciones preventivas más eficaces.

## 🛠️ Tecnologías Utilizadas
* **Python:** Limpieza de datos (Pandas/NumPy) y Modelado de Machine Learning (Scikit-Learn).
* **Tableau:** Visualización avanzada y creación de Dashboards de salud.
* **Estadística:** Análisis de comorbilidades y correlación de variables clínicas (Glucosa, Edad, Tabaquismo).

## 📈 Hallazgos Clave
1. **El factor edad:** Se identificó un riesgo del **24.4%** en pacientes Senior con dos comorbilidades (Hipertensión y Enfermedad Cardíaca).
2. **Sesgo en Tabaquismo:** Los exfumadores presentan una incidencia mayor que los fumadores activos en este dataset, sugiriendo un diagnóstico reactivo tras el cese del hábito.
3. **Dispersión de Glucosa:** Los niveles elevados de glucosa muestran una correlación visual clara con el aumento de casos en grupos de edad avanzada.
